# 任务拆分 · 午夜落槌 · 藏品连锁

> 生成日期：2026-09-20

> 原型来源：无

## 概览

| 项 | 内容 |
|---|---|
| 项目名称 | 午夜落槌 · 藏品连锁（三场卡牌肉鸽原型） |
| 项目类型 | 非服务化（PC 本地离线单机；无服务端、无数据库服务、无 MQ、无定时任务、无回调） |
| 涉及角色 | 前端（TypeScript / React）、桌面壳工程（Tauri v2）、测试（QA） |
| 模块数量 | 6 个 |
| 任务总数 | 33 条 |
| 页面数量 | 7 个页面 + 2 个弹窗 |
| 接口数量 | 11 个本地 AI 接口（含 1 个批量回归 CLI 入口） |
| 交付范围 | 全量交付（用户确认 U-01）：PRD §19 全部验收用例单期完成 |
| 技术栈 | TypeScript + Vite + React 18 + Vitest；桌面壳 Tauri v2（用户确认 U-02、U-05） |

## 模块任务详情

### 模块：规则内核（M1）

- **业务职责**：以纯 TypeScript 实现全部游戏规则（结算算法、状态机、随机流、卡牌能力、场次与资源），保证零 DOM / 零平台依赖、结果确定可复现，供界面与 AI 接口共用
- **依赖模块**：无（核心链路起点，必须先行）

- **业务职责**：提供原子、可校验、可迁移的本地存档读写，保证"内存与存档同事务一致"，并把存档作为不可信输入做全量校验；按载体提供两个适配器——浏览器版 `LocalStorageAdapter`、桌面壳 `SqliteAdapter`（**U-07：桌面壳强制 SQLite，非可选**）
- **依赖模块**：M1
