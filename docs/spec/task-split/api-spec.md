| 项 | 内容 |
|---|---|
| 项目名称 | 午夜落槌 · 藏品连锁（三场卡牌肉鸽原型） |
| 接口总数 | 11 个 |
| 覆盖模块 | M3 本地 AI 接口与批量回归 |

## 模块：本地 AI 接口与批量回归（M3）

| 序号 | 接口路径 | 方法 | 功能说明 |
|---|---|---|---|
| 1 | `auction.ai.start` | 本地 JSON 请求 | 以指定种子（或自动生成短种子）创建新局，返回持久会话 ID 与公开初始视图（第 1 场、6 张手牌、剩余出牌 4 次、撤换 2 次）；可选 `persist: true` 绑定玩家存档用于调试（默认不绑定，避免污染进度） |
| 2 | `auction.ai.observe` | 本地 JSON 请求 | 返回当前公开状态（阶段、场次进度、资源、手牌、收藏、排列槽、保底预览、奖励候选、结果）；不改变任何状态，不推进随机流 |
| 3 | `auction.ai.preview` | 本地 JSON 请求 | 传入有序实牌 ID（3 个），返回该顺序的**保底**结算：累计点数、热度、成交价与确定性流水（红手套标注"未计入保底"）；不改变会话状态与随机流 |
| 4 | `auction.ai.act.play` | 本地 JSON 请求 | 按 `ids` 顺序出牌并执行实际结算（含红手套 50% 判定），成交价入账、3 张牌进弃牌区、消耗 1 次出牌次数，返回流水与最新 `seq` |
| 5 | `auction.ai.act.mulligan` | 本地 JSON 请求 | 将 1–3 张手牌放入弃牌区并立即补至 6 张，消耗 1 次撤换次数；不消耗出牌次数、不产生分数 |
| 6 | `auction.ai.act.continue` | 本地 JSON 请求 | 结算继续，按固定顺序判定：达标且非第 3 场→奖励阶段；第 3 场达标→通关；未达标且仍有次数→补牌进入下一轮；未达标且次数耗尽→失败（最后一轮达标优先判胜） |
| 7 | `auction.ai.act.collect` | 本地 JSON 请求 | 从 3 个候选模板中选择 1 个，创建新实牌（点数加成 0、ID 唯一）加入收藏并进入升级阶段；重复领取被拒绝 |
| 8 | `auction.ai.act.upgrade` | 本地 JSON 请求 | 指定 1 张实牌永久点数 +2，完成后立即进入下一场（重置出牌/撤换次数、重新洗牌、抽至 6 张）；重复升级被拒绝 |
| 9 | `auction.ai.history` | 本地 JSON 请求 | 返回本会话已完成轮次的结算摘要与完整流水（场次、轮次、顺序、点数、热度、成交价、保底价、流水），用于回归比对 |
| 10 | `auction.ai.close` | 本地 JSON 请求 | 关闭会话并释放资源；不修改存档、不结束本局；重复关闭返回 `SESSION_NOT_FOUND` |
| 11 | `npm run ai -- --jsonl` | CLI（stdin/stdout JSONL） | 批量回归入口：逐行读入请求 JSON、逐行输出响应 JSON，同一进程内保持会话状态；退出码 0=全部成功、1=存在失败响应、2=输入格式错误 |

### 公共约定（简版摘要）

| 项 | 约定 |
|---|---|
| 请求版本 | `schemaVersion` 固定为 `2`（PRD §17）；其他值返回 `PROTOCOL_VERSION_UNSUPPORTED` |
| 变更类操作 | 必须携带 `sessionId` 与 `seq`；`seq` 必须等于当前会话序号，成功后 `seq += 1` |
| 幂等保护 | 重复提交同一 `seq` 返回 `RULE_STALE_SEQ`；奖励/升级另有阶段与标记双重保护；结算入账只在出牌时发生一次 |
| 公开信息白名单 | 手牌、收藏、阶段、场次进度、排列槽、保底预览、奖励候选、结算与公式；**不返回**抽牌堆顺序、弃牌区顺序、三条随机流状态、`nextCardSeq` |
| 错误结构 | `{"ok":false,"error":{"code":"<RULE_*|SAVE_*|SESSION_*|PROTOCOL_*>","message":"...","context":{...}}}` |
| 鉴权 / 限流 | 无（本地离线，无账号体系） |

### 请求 / 响应示例（简版）

```json
{"schemaVersion":2,"operation":"start","seed":"review-01"}
```

```json
{
  "schemaVersion": 2,
  "operation": "act",
  "sessionId": "<id>",
  "seq": 0,
  "decision": {"type": "play", "ids": ["c4", "c6", "c7"]}
}
```

```json
{"schemaVersion":2,"operation":"preview","sessionId":"<id>","decision":{"type":"preview","ids":["c4","c6","c7"]}}
```
